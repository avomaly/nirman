# VØID // DISTRICT

A multi-section frontend website for a fictional technical streetwear and archive apparel brand, built with 100% pure semantic HTML5 and CSS3 (Zero JavaScript).

## Features
- **Hero & Announcement**: Bold brutalist typography, high-contrast imagery, and call-to-action buttons.
- **Specifications Strip**: 3-metric industrial garment standards (480 GSM fleece, Cordura® hybrid, zero restocks).
- **Pure CSS Category Filter**: Interactive filtering (`ALL PIECES`, `OUTERWEAR`, `FLEECE`, `BOTTOMS`, `GEAR`) powered by hidden radio inputs and CSS `:checked ~` combinators.
- **Lookbook Lightbox**: Full-screen modal viewing using native CSS `:target` pseudo-class with smooth backdrop dismiss.
- **Brand Story / Manifesto**: Two-column layout exploring technical fabrics, structural tolerances, and atelier philosophy.
- **FAQ / Info Accordion**: Collapsible details section for shipping, returns, sizing, and garment care built with native `<details>` and `<summary>`.
- **Pure CSS Mobile Navigation**: Accessible mobile drawer toggle powered by the checkbox hack and CSS `:has()`.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

## Tech Stack
- **HTML5**: Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>`, `<details>`, `<summary>`)
- **CSS3**: Design tokens (variables), Flexbox, CSS Grid, `:target`, `:has()`, `:checked`
- **Typography**: Syne, Space Grotesk, Space Mono (Google Fonts)
